# Packet Tracer — Configure a Wireless Router and Clients

##  Описание

Лабораторная работа выполнена в **Cisco Packet Tracer**.

В рамках работы была построена и настроена небольшая домашняя сеть с проводными и беспроводными клиентами. В качестве центрального устройства использовался домашний беспроводной маршрутизатор.

Основная задача — подключить сетевые устройства, настроить маршрутизатор, создать защищённую Wi-Fi сеть, получить IP-адреса по DHCP и проверить доступ к интернету.

---

##  Цели лабораторной работы

* Подключить сетевые устройства в Cisco Packet Tracer.
* Настроить домашний Wireless Router.
* Настроить DHCP.
* Настроить беспроводную сеть Wi-Fi.
* Настроить WPA2 Personal.
* Подключить ноутбук к Wi-Fi.
* Проверить получение IP-адресов.
* Проверить подключение устройств к интернету.

---

| Устройство      | Назначение                     |
| --------------- | ------------------------------ |
| Wireless Router | Центральное сетевое устройство |

| Office PC       | Проводной клиент               |
| Bedroom PC      | Проводной клиент               |

## 🌐 Топология

В лабораторной работе домашний Wireless Router является центральным устройством сети.

```text
                         Internet
                            │
                       Cable Modem
                            │
                            │
                    ┌───────┴───────┐
                    │ Wireless      │
                    │ Router        │
                    │               │
                    └───┬───────┬───┘
                        │       │
                       PC      PC
                               
                         ))))
                      Wi-Fi

```

## 🔌 Часть 1 — Подключение устройств

Сначала были подключены основные устройства домашней сети.

### Коаксиальное подключение

Cable Splitter используется для разделения кабельного сигнала:

* `Coaxial1` → Cable Modem
* `Coaxial2` → TV

После подключения телевизора проверяется наличие видеосигнала.

### Ethernet-подключения

Cable Modem подключается к Internet-порту Wireless Router.

Проводные компьютеры подключаются к LAN-портам маршрутизатора.

Таким образом, Wireless Router становится центральной точкой домашней сети.

---

## ⚙️ Часть 2 — Настройка Wireless Router

### DHCP

Для Office PC был включён режим DHCP.

После получения адреса компьютером определяется **Default Gateway**, который соответствует адресу домашнего Wireless Router.

DHCP используется для автоматической выдачи IP-параметров клиентам.

---

### Основные настройки

Количество DHCP-клиентов было ограничено:

```text
Maximum Number of Users: 10
```

Это соответствует условию лабораторной работы.

---

### Настройка администратора

Стандартный пароль маршрутизатора был изменён.

```text
Username: admin
Password: MyPassword1!
```

Изменение стандартных учётных данных повышает безопасность управления маршрутизатором.

---

## 📶 Настройка Wi-Fi

Для беспроводной сети 2.4 GHz был включён радиомодуль.

### SSID

Название сети изменено:

```text
Default → MyHome
```

После этого беспроводная сеть отображается клиентам под именем:

```text
MyHome
```

---

## 🔐 Настройка безопасности

Для Wi-Fi была включена защита:

```text
Security Mode: WPA2 Personal
```

Парольная фраза:

```text
MyPassPhrase1!
```

Таким образом, подключиться к беспроводной сети без предварительно заданного ключа невозможно.

---

## 💻 Часть 3 — Подключение клиентов

### Laptop

На ноутбуке был настроен беспроводной адаптер.

Последовательность подключения:

```text
Laptop
   ↓
Desktop
   ↓
PC Wireless
   ↓
Connect
   ↓
MyHome
   ↓
MyPassPhrase1!
```

После подключения проверяется информация о соединении.

Клиент должен получить IP-адрес из локальной сети.

---

## 🧩 IP-адресация

В лабораторной работе клиенты используют DHCP.

Пример полученной конфигурации:

| Параметр        | Значение      |
| --------------- | ------------- |
| IP Address      | 192.x.x.x     |
| Subnet Mask     | 255.255.255.0 |
| Default Gateway | 192.x.x.x     |
| DHCP            | Enabled       |

Конкретные значения IP-адресов зависят от результата работы DHCP в Packet Tracer.

## 🧪 Проверка подключения

Для проверки использовался:


На клиентах открывался Web Browser и проверялось подключение к серверу.

Успешная загрузка страницы подтверждает работоспособность сетевого подключения.

## 🐛 Troubleshooting

Во время выполнения лабораторной работы необходимо учитывать, что получение IP-адреса клиентом может занимать некоторое время из-за симуляции Packet Tracer.

Если устройство не получает IP-адрес:

```text
1. Проверить физическое подключение.
2. Проверить состояние интерфейсов.
3. Проверить DHCP.
4. Обновить IP-конфигурацию.
5. Использовать Fast Forward Time в Packet Tracer.
6. Повторно проверить соединение.
```
